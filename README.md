## Проекты

### [Telegram-бот для онлайн-записи](https://github.com/Lizy49/booking-bot)

Демонстрационный бот для барбершопа, мастера, репетитора или небольшой студии.

- Запись клиента на услугу, дату и свободное время.
- Просмотр и отмена собственных записей.
- Уведомления администратора о новых и отменённых записях.
- SQLite для хранения записей.
- Проверка расписания и защита от двойной записи.

**Стек:** Python, Telegram Bot API, SQLite, `unittest`.
